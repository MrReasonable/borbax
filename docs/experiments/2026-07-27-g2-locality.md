# G2 — does signature space have locality?

**Measured 2026-07-27.** Reproduce with:

```bash
cargo run -p borbax-experiments --release --bin g2
```

## The question

Spec §8.4's evolvability argument assumes a one-atom edit moves a molecule a
*small* distance in signature space — that chemistry is explorable by small
steps rather than by teleportation. Nothing had ever measured that. An earlier
harness suggested it might be false, which would falsify a design premise
rather than reveal a bug, so it gated Tasks 8 onward.

## The method

Each trial draws a parent molecule, applies one single-atom edit, and draws an
unrelated molecule independently. Every descriptor answers one question: **is
the mutant nearer to its parent than a stranger is?** Aggregated over trials
that gives a concordance index — `1.0` perfect locality, `0.5` none.

Four descriptors, differing only in what they do about orientation:

| Distance   | Orientation handled by                            |
|------------|---------------------------------------------------|
| `D_frame`  | rotating into a frame anchored to canonical atoms |
| `D_raw`    | nothing — compared as embedded                    |
| `D_group`  | minimising over all 60 rotations                  |
| `D_sorted` | discarding it, by sorting the extents             |

Two regimes. Unrelated molecules are normally drawn at their own size, so a
descriptor can score well just by tracking how big something is; the
**size-matched** regime holds atom count equal and leaves only shape.

## The controls

The run reports nothing unless both controls behave. This is not ceremony —
six earlier harnesses produced figures nobody can now check, and the only
difference between a measurement and a number is whether the instrument was
calibrated.

- **Positive control: composition** (L1 between per-element atom counts). Uses
  no geometry. Locality is present *by construction* — a one-atom edit changes
  it by at most two — so a harness that cannot see it here cannot see it at
  all. Composition rather than bare atom count, which is the obvious choice and
  is wrong: under size matching every molecule has the same atom count, so that
  control reads a flat zero and would certify a broken instrument.
- **Negative control: an avalanched hash of the canonical form.** It identifies
  the species exactly, so it carries strictly more information than any
  signature — but the hash destroys all similarity structure, so it *must* show
  nothing. A reading away from `0.5` means the statistic is manufacturing
  signal.

`Report::check_controls` enforces both and has five tests of its own, covering
blind-positive, leaking-negative, inverted-negative, missing and non-finite
controls.

## Result

2000 trials × 5 independent seeds, both regimes, controls passing throughout.
Concordance range across seeds:

| descriptor              | free size       | size-matched    |
|-------------------------|-----------------|-----------------|
| `D_group`               | 0.966 – 0.973   | 0.923 – 0.942   |
| `D_raw`                 | 0.956 – 0.967   | 0.908 – 0.936   |
| `D_sorted`              | 0.945 – 0.954   | 0.884 – 0.908   |
| `D_frame`               | 0.920 – 0.938   | 0.859 – 0.889   |
| control+ (composition)  | 0.993 – 0.996   | 0.979 – 0.982   |
| control− (form hash)    | 0.496 – 0.515   | 0.485 – 0.511   |

The ordering `D_group > D_raw > D_sorted > D_frame` holds on every seed in both
regimes, with gaps wider than the spread.

## Conclusions

**1. Locality is present and strong. §8.4's premise is not falsified.** Every
descriptor sits far above the 0.5 floor the negative control establishes.

**2. Drop `canonicalise_frame`.** The label-anchored frame is the worst of the
four — worse than doing no alignment at all. It also *raises* the median
parent-to-mutant distance (2.49 against `D_raw`'s 1.70): it is adding
displacement rather than removing it, because the frame jumps discontinuously
when a one-atom edit changes which atom comes first in canonical order. The
frame is genuinely canonical — that is tested — but canonical is not the same
as continuous, and continuity is what locality needs.

**3. Use `D_group`.** It is the best of the four *and* it is already what the
binding kernel does. Adopting it removes a mechanism instead of adding one,
which is §8.3's "one mechanism, reused at every scale" paying out.

**4. Size is not the whole story.** Removing size as a signal costs only ~0.05
concordance. Quote the size-matched column for any claim about shape.

## What this does not say

The earlier harness reported that **32%** of one-atom mutants land further from
their parent than an unrelated molecule does. This harness measures **8.1%**
(free size) and **14.1%** (size-matched) for `D_frame` on the same statistic.

That is not a refutation. The earlier harness no longer exists, had no
controls, and differed in molecule distribution and size range as well as in
descriptor detail. The two numbers are not comparable; the figure should be
re-derived from this harness from now on.

The harness measures tree molecules of 8–20 atoms with four element types. It
says nothing about the separate G1 finding that binding is ~93% size and ~7%
shape — that is a different question about `ideal_gap`, still open.
